## 🛠️ Hướng Dẫn Chạy Một Bài Lab

Để chạy bất kỳ bài lab nào, mở terminal và điều hướng vào thư mục bài lab tương ứng:

```bash
# 1. Di chuyển vào thư mục bài lab (ví dụ: lab1)
cd lab1

# 2. Cài đặt các dependencies
flutter pub get

# 3. Chạy ứng dụng trên thiết bị / emulator / web
flutter run
```
