Cách chạy trực tiếp bằng Flutter CLI trên máy

Để chạy bằng lệnh flutter run:

  1. Tải Flutter SDK từ flutter.dev và giải nén (khuyên đặt vào D:\flutter vì ổ C: chỉ còn ~3.7 GB).
  2. Thêm D:\flutter\bin vào biến môi trường PATH.
  3. Mở terminal tại thư mục bài lab:
    cd d:\DANENTANG\lab1
    flutter run
